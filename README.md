# Technology Portfolio — Victoria Zúñiga Fernández

Single-page professional portfolio built with plain HTML, CSS and JavaScript. It requires no installation or external dependencies.

## Open locally

Double-click `index.html`, or open it from any browser.

## Publish with GitHub Pages

1. Create a GitHub repository and upload `index.html` to its root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

## Before publishing

- Add GitHub project links if the repositories will be public.
- Add a professional email or CV link in the Contact section if desired.
- Replace the summarized Professional Experience block with exact employer names and dates if appropriate for the public version.

The site is responsive, keyboard-accessible and includes reduced-motion support.

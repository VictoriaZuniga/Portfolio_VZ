03 / FEATURED CASE STUDY

Biblioteca Digital

01

The project

Biblioteca Digital is a Java web application developed to manage library-related information and operations while integrating presentation, business logic, relational persistence and application deployment.

02

The challenge

The main challenge was connecting Java logic, JSP/JSTL views, MySQL persistence and Apache Tomcat. This also required resolving configuration, dependency, connection and deployment issues.

03

The solution

The application was organized by separating presentation, application logic and persistence responsibilities. MySQL provided relational storage, Tomcat ran the application and the completed project was packaged as a WAR file for deployment.

04

Tools and technical skills

Java · JSP · JSTL · SQL · MySQL · Apache Tomcat · WAR packaging · Web application deployment · Debugging · Component integration.

05

WAR packaging completed
06

Key learnings

The project strengthened my understanding of how a Java web application's components interact. It also developed my ability to diagnose issues systematically, test each component progressively and resolve integration and deployment problems.

07

Why this project?

I selected Biblioteca Digital because it clearly represents my technical growth. It required me to integrate programming, databases and web technologies into one working solution while applying persistence, configuration, troubleshooting and deployment skills.
